# PeerChat: Peer-to-Peer Messaging Library

UDP peer-to-peer messaging library backed by a C networking core.
Provides R bindings for creating sockets, discovering peers via a
central synchronization server written in C, and exchanging messages
directly between clients without relaying through the server. It
leverages a custom made data protocol.
